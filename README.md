## Projekte (Vorschau)

### Rocket Blaster

Kurzbeschreibung:
Ein kleines 2D-Arcade-Spiel, in dem du eine Rakete steuerst, Hindernissen ausweichst und Gegner mit deinem Blaster bekämpfst. Ziel ist es, so lange wie möglich zu überleben und den Highscore zu knacken.

Technologien:
- Python
- Pygame (für das Spiel-Framework)

Features:
- Steuerung der Rakete (Tasten oder Maus)
- Verschiedene Gegner- und Asteroiden-Typen
- Power-Ups (Schild, schneller Schuss)
- Highscore-Speicherung

Schnellstart (lokal):
1. Python 3.8+ installieren
2. Abhängigkeiten installieren:

```bash
pip install -r requirements.txt
```
3. Spiel starten:

```bash
python rocket_blaster.py
```

Eine einfache Web-App, mit der du Filme sammeln, bewerten und durchsuchen kannst. Ideal als kleines CRUD-Projekt, das JavaScript im Frontend und eine einfache JSON- oder lokale Storage-Lösung verwendet.
